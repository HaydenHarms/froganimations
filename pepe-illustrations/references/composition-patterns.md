# Composition patterns and originality rules

## Structure types

Pick one. Don't mix several.

### Workflow
For: input → processing → output, content production, AI workflows, automation chains.
Draw: inputs on the left, Pepe or a strange machine processing in the middle, outputs on the right, an orange arrow for the main flow.

### System close-up
For: information sources, filters, databases, renderers, part of an agent system.
Draw: only 3-5 core modules. Pepe does the key action in one of them.

### Before / after
For: messy vs ordered, manual vs automatic, scattered vs gathered, anxious vs stable.
Draw: mess on the left, stable on the right, an orange arrow between. Pepe can be more exaggerated here.

### Character states
For: user pain points, creator states, too many tools, information overload, from stuck to running.
Draw: 2-4 small states, one short label each.

### Concept metaphor
For: content factory, information warehouse, the black box in your head, workflow machine, automatic daily report.
Draw: one big strange object or machine, a few inputs, one output. Make it memorable.

### Layers
For: frameworks, system layers, capability stacks, layered content systems.
Draw: stacked boxes, never a formal pyramid. Pepe hauling bricks or building alongside.

### Route map
For: idea to launch, user journey, handoff path, learning path.
Draw: one winding path, a few nodes, Pepe pulling the line or walking it.

### Mini comic
For: failure to success, a real process, a gripe, before-and-after use.
Draw: 2-4 small panels, one action per panel.

## Inventing a fresh metaphor

Invent the metaphor from the current material every time. Don't lift old pictures.

### Three steps

1. Turn the abstract idea into a physical action: getting stuck, leaking, getting heavier, sorting, settling, fermenting, opening a door, folding, unpacking, flowing back.
2. Turn the system structure into a low-tech object: a broken machine, a cardboard box, a drawer, a pipe, a mailbox, a strange dial, a scale, a well, a ladder, a suitcase, a strange workstation.
3. Give Pepe the action: not standing beside it, but stuck in the machine, pulling the wrong wire, guarding the gate, hauling, patching, weighing, steadying a ladder, taking notes, stuffing something into a strange device, sitting on a lid to force it shut.

### Object pool
Cardboard box, drawer, old machine, funnel, scale, mailbox, door, well, ladder, pipe, ball of yarn, sluice gate, turntable, black box, hole punch, pasta press, clothesline, suitcase, odd workstation.
Use 1-2 per picture. Don't pile them up.

### Action pool
Pull, carry, stuff, scoop, press, weigh, sew, cut, twist, guard, push, catch, unpack, mark, recycle, sit on.
The action must serve the core idea. Don't be weird for the sake of weird.

## Don't copy

Don't open or copy `assets/examples/` or `assets/svg-examples/` by default. They're for calibrating style (line density, white space, colour restraint, detail level, how the character takes part).

Unless the user says "like this one", "copy this composition" or "change this example", don't reuse these compositions:

- conveyor belt with two breakpoints
- character inside a content machine pulling the "judgment" lever
- character as a funnel sorting traffic / trust / conversion
- character slicing a "material fish"
- character leading a handoff path
- character pulling three layers of sources together
- three characters with megaphone / bridge / door
- character stamping a script toolbox
- character holding a sign at a common-pitfalls path
- character sitting on an overstuffed "context" suitcase

Find a new metaphor even for the same topic. A "handoff path" doesn't have to be a road: Pepe could tie the tail of the content to a door handle. "One fish, many meals" doesn't have to be a fish: Pepe could press one lump of dough into several shapes.
